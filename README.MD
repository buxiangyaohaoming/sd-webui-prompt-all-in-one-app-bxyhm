This fork adds AI-assisted features and fixes on top of the original.

## ✨ New Features

### 🔍 Character Name Search

Search characters by name in the tag sidebar with autocomplete suggestions.

![Character Search](./assets/screenshot-character-search.png)

### 📺 Series-Based Browsing

Browse characters grouped by series (e.g., Idolmaster, Uma Musume, Touhou Project) for faster navigation.

- **Tag Search**: Fuzzy search Danbooru tags in both Chinese and English
- **Unified Search**: Simultaneously search tags, characters, and combos

### 🧩 Combo Management

- **Presets**: Save frequently used prompt tag combinations
- **Manager**: Create, edit, and delete custom tag combos

## 📥 Installation

### Option 1: Git Clone (Recommended)

```bash
git clone https://github.com/buxiangyaohaoming/sd-webui-prompt-all-in-one-app-bxyhm.git --recurse-submodules
cd sd-webui-prompt-all-in-one-app-bxyhm
pip install -r requirements.txt
python app.py
```

### Option 2: Download ZIP

Download the latest ZIP from [Releases](https://github.com/buxiangyaohaoming/sd-webui-prompt-all-in-one-app-bxyhm/releases), extract and run:

```bash
pip install -r requirements.txt
python app.py
```

### Access

Open [http://localhost:17860](http://localhost:17860) in your browser.

To change port, username, or password, copy `.env.example` to `.env` and edit it.
